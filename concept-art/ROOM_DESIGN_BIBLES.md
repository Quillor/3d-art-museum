# Museum Room Design-Bible Registry

Status: authoritative research and scope registry. No room is production-approved.

The old Hallway PNGs and the per-room README concept descriptions are retained only as mood and composition history. They are not evidence for architecture, motifs, unseen geometry, color, or texture. When those files conflict with this registry or with [room-designs.json](./room-designs.json), this registry and the JSON file win. Production requirements and release gates live in [PRODUCTION_STANDARD.md](./PRODUCTION_STANDARD.md).

## How to read the registry

- Collection scope describes which objects a room may display.
- Architectural frame names the one culture, place, structure, and construction phase that may shape the shell and entrance. It does not claim to represent the whole collection scope.
- Every hexadecimal palette in room-designs.json is a museum design adaptation based on the documented material family. It is not an archaeological claim about an exact recovered color.
- A verified anchor is not approval to model. Each room still needs measured evidence, a completed Bible, orthographic plates, material provenance, signage tests, and all G0-G8 approvals.
- Living, Indigenous, sacred, or active religious references require the named cultural-review gate before concept or asset release.
