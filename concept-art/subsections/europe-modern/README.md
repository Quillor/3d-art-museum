# Europe Modern Hallway Concept Spec

**Period:** 1900-1950  
**Gallery read:** Bauhaus/early modern gallery  
**Concept sheet:** `Hallway-13-europe-modern.png`  
**Core material language:** terrazzo, concrete, matte plaster, steel, pale oak, glass

## Online Reference Links Used
- [Bauhaus Dessau](https://www.bauhaus-dessau.de/en/index.html)
- [Tate: Modernism](https://www.tate.org.uk/art/art-terms/m/modernism)
- [MoMA: Architecture and design](https://www.moma.org/collection/terms/architecture-and-design)

## High-Level Art Direction
A clean modernist corridor with plaster planes, terrazzo/concrete floors, steel rails, simple wood details, and controlled daylight. The sheet is intended as production concept art for a museum subsection: dark editorial board, large cinematic architectural panels, concise captions, and materials readable enough for asset modeling.

## Floor Texture / Material Notes
Terrazzo or polished concrete fits the period; avoid decorative 19th-century parquet here unless staging a transitional room.

Texture priority for Blender materials: terrazzo, concrete, matte plaster. Use roughness, bump, and bevels to make the floor catch light without creating unsafe visitor-path geometry.

## Blender Asset-Generation Guidance
Build rectilinear portal blocks, plaster wall planes, skylight strips, steel trim, and terrazzo/concrete material variants. Keep the corridor kit modular and shallow enough to wrap the existing museum path rather than becoming a separate scene. Preserve calm wall zones for artwork, and place ornament as framing, trim, ceiling, floor, or portal detail.

## Suggested Assets To Model
- Modernist portal
- Terrazzo floor
- Plaster wall plane
- Steel rail
- Sawtooth skylight

## Runtime Integration Notes
This folder is concept-art only. When these designs are promoted into runtime assets, keep file changes outside this folder intentional and map the materials onto existing corridor segments.
