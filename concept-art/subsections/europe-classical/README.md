# Europe Classical Hallway Concept Spec

**Period:** 800 BCE-500 CE  
**Gallery read:** Greco-Roman stone gallery  
**Concept sheet:** `Hallway-07-europe-classical.png`  
**Core material language:** marble, mosaic, carved limestone, coffered ceiling, bronze

## Online Reference Links Used
- [Met: Greek and Roman Art](https://www.metmuseum.org/toah/hd/grarc/hd_grarc.htm)
- [British Museum: Ancient Greece and Rome](https://www.britishmuseum.org/collection/galleries/greece-and-rome)
- [Smarthistory: Roman architecture](https://smarthistory.org/roman-architecture/)

## High-Level Art Direction
A colonnaded architectural gallery with coffered ceilings, stone entablatures, mosaic/marble floors, and warm museum daylight. The sheet is intended as production concept art for a museum subsection: dark editorial board, large cinematic architectural panels, concise captions, and materials readable enough for asset modeling.

## Floor Texture / Material Notes
Marble slab or mosaic flooring is plausible; avoid modern concrete and generic square pavers.

Texture priority for Blender materials: marble, mosaic, carved limestone. Use roughness, bump, and bevels to make the floor catch light without creating unsafe visitor-path geometry.

## Blender Asset-Generation Guidance
Use fluted column modules, entablature beams, coffered ceiling panels, and mosaic floor material slots. Keep the corridor kit modular and shallow enough to wrap the existing museum path rather than becoming a separate scene. Preserve calm wall zones for artwork, and place ornament as framing, trim, ceiling, floor, or portal detail.

## Suggested Assets To Model
- Column portal
- Coffered ceiling
- Mosaic floor tile
- Entablature trim
- Bronze lamp

## Runtime Integration Notes
This folder is concept-art only. When these designs are promoted into runtime assets, keep file changes outside this folder intentional and map the materials onto existing corridor segments.
