# Mesoamerica Hallway Concept Spec

**Period:** 1200 BCE-1520 CE  
**Gallery read:** Stepped limestone temple gallery  
**Concept sheet:** `Hallway-02-americas-mesoamerica.png`  
**Core material language:** limestone, volcanic stone, greca friezes, carved lintels, matte plaster traces

## Online Reference Links Used
- [Met: Mesoamerica](https://www.metmuseum.org/toah/hd/ma/hd_ma.htm)
- [UNESCO: Pre-Hispanic City of Teotihuacan](https://whc.unesco.org/en/list/414/)
- [UNESCO: Ancient Maya City of Calakmul](https://whc.unesco.org/en/list/1061/)

## High-Level Art Direction
A temple-derived museum passage using stepped massing, geometric fretwork, carved relief bands, and warm light across weathered stone. The sheet is intended as production concept art for a museum subsection: dark editorial board, large cinematic architectural panels, concise captions, and materials readable enough for asset modeling.

## Floor Texture / Material Notes
Use large weathered limestone or volcanic slabs rather than small generic block paving.

Texture priority for Blender materials: limestone, volcanic stone, greca friezes. Use roughness, bump, and bevels to make the floor catch light without creating unsafe visitor-path geometry.

## Blender Asset-Generation Guidance
Model repeatable stone bays with greca band trim, stepped plinths, blocky piers, and a ceremonial threshold piece. Keep the corridor kit modular and shallow enough to wrap the existing museum path rather than becoming a separate scene. Preserve calm wall zones for artwork, and place ornament as framing, trim, ceiling, floor, or portal detail.

## Suggested Assets To Model
- Stepped portal
- Greca frieze strip
- Carved stone wall bay
- Large limestone floor slabs
- Low artifact niche

## Runtime Integration Notes
This folder is concept-art only. When these designs are promoted into runtime assets, keep file changes outside this folder intentional and map the materials onto existing corridor segments.
